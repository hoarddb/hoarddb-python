# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
with GitHub's private vulnerability reporting: open the **Security** tab of this
repository (hoarddb-python on GitHub, under the hoarddb organisation) and choose
**Report a vulnerability**.

Include what you found, the version or commit, and the steps to reproduce it.
We read every report and will reply in the advisory thread.

## Supported versions

hoarddb-python is pre-release. Fixes are made on the main branch.
